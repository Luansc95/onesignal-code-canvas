# OneSignal Showcase

Criar Site Institucional e Portfólio Profissional — OneSignal
Crie um site institucional moderno, premium e totalmente responsivo para uma empresa de tecnologia chamada OneSignal, seguindo como principal referência visual a identidade presente nas imagens fornecidas pelo usuário.
O objetivo do site é apresentar a empresa, divulgar serviços tecnológicos, expor projetos desenvolvidos em formato de portfólio e gerar novos contatos comerciais e solicitações de orçamento.
1. IDENTIDADE VISUAL E DIREÇÃO DE DESIGN
A identidade visual deve transmitir:
Tecnologia
Inovação
Modernidade
Confiança
Profissionalismo
Soluções empresariais
Sofisticação
Utilize uma estética tecnológica semelhante à referência visual enviada:
Fundo predominantemente azul escuro
Gradientes em azul, ciano e turquesa
Elementos futuristas sutis
Linhas digitais e conexões tecnológicas
Efeitos luminosos discretos
Cards modernos
Bordas arredondadas
Sombras suaves
Efeito glassmorphism utilizado com moderação
Animações elegantes e leves
Excelente legibilidade
A marca principal deve aparecer como:
OneSignal
Utilizar uma apresentação visual profissional e tecnológica, seguindo o estilo da referência enviada, mas sem simplesmente copiar outros layouts ou elementos externos. Criar uma identidade própria e consistente para todo o site.
Paleta sugerida
Azul profundo: #071B3A
Azul tecnológico: #0B4F7A
Ciano: #22D3EE
Turquesa: #2DD4BF
Branco: #F8FAFC
Tons complementares de azul para gradientes e fundos
O resultado deve parecer o site de uma empresa de desenvolvimento de software consolidada e inovadora.
